# ScrollMark

Firefox add-on that bookmarks exact positions inside webpages and brings you back to them later.

## Features
- Save the current position from the toolbar popup.
- Right-click any spot and choose **Bookmark this position with ScrollMark**.
- Keyboard shortcut to save (Alt+Shift+S by default).
- Opened positions are briefly highlighted so you see where you landed.
- Multiple positions per page, with search, rename and delete.
- Export and import your bookmarks as JSON.
- Everything stays local in your Firefox profile.
